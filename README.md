ResiRamos 🌿


Vitrine virtual para peças artesanais em resina, desenvolvidas sob medida.


📋 Sobre o Projeto

O ResiRamos é uma vitrine virtual desenvolvida para apresentar e divulgar peças artesanais em resina produzidas sob encomenda. O site foi criado com foco em elegância, leveza e experiência do usuário, tanto em desktop quanto em dispositivos móveis.

O projeto nasceu da necessidade real de um canal de divulgação profissional para um negócio artesanal, substituindo a dependência exclusiva de redes sociais.

✨ Funcionalidades


Carrossel de fotos por produto com navegação por setas e pontinhos indicadores
Suporte a swipe (deslize) em dispositivos móveis
Layout responsivo adaptado para celulares, tablets e desktop
Integração direta com WhatsApp para solicitação de encomendas
Design elegante em tema escuro com paleta dourada


🛠️ Tecnologias Utilizadas


HTML5 — estrutura semântica
CSS3 — layout com Grid, variáveis CSS, Flexbox e media queries
JavaScript — lógica do carrossel com suporte a touch
Google Fonts — tipografia Cinzel
GitHub Pages / Vercel — hospedagem

🚀 Como Rodar Localmente

Não é necessário instalar nada. Basta clonar o repositório e abrir o arquivo index.html no navegador:

git clone https://github.com/Souza-Gustavo/resiramos-site.git
cd resiramos-site

Abra o arquivo index.html diretamente no navegador.

🌐 Acesse o Site

🔗 resiramos.vercel.app
